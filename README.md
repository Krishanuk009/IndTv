# GitHub File Manager
A professional, mobile-first web interface for managing GitHub repositories.

## Installation
1. Upload all files to InfinityFree `htdocs`.
2. Rename `config/config.example.php` to `config/config.php`.
3. Set your GitHub Token (with 'repo' or 'contents' scope).
4. Set a secure Admin password hash in `config.php`.
5. Ensure the `uploads/` directory is writeable.
